# Machine Learning from Scratch

Implementing machine learning and deep learning algorithms from scratch to understand the math and mechanics behind them.

Each project lives in its own folder under `projects/` and has its own setup instructions and dependencies.

## Projects

- [MNIST neural network](projects/mnist-neural-network/README.md): a starting point for building a handwritten digit classifier from scratch. The dataset loader is ready; the neural network is yours to implement.
